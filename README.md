# MCTA 4364 Machine Vision — Hands-On Notebooks

Jupyter notebooks for a 14-week machine-vision course: **two notebooks per week, one for each 80-minute session**.
The course runs from pixels and cameras through classical image processing to deep learning, detection, tracking,
segmentation, 3D vision, vision-language models and generative AI, with a strong focus on **industrial machine vision**
and **data-centric engineering**.

Every notebook contains learning outcomes and a session plan, theory with equations, many figures, real openly licensed images,
interactive widgets, exercises with automatic self-checks, an auto-marked quiz, references and key takeaways.
See **[SYLLABUS.md](SYLLABUS.md)** for the full course plan.

## Running the notebooks

- **Google Colab** (easiest): click a badge. For Weeks 6–13 choose *Runtime → Change runtime type → T4 GPU*.
- **Kaggle:** *File → Import Notebook → GitHub URL*, then enable *Internet* and a *GPU* in the settings.
- **Your laptop** (recommended from Week 6, a 4 GB NVIDIA GPU is enough): follow **[SETUP.md](SETUP.md)**, then run
  `notebooks/W00_setup/W00_setup_check.ipynb`.

The first cell of every notebook installs any missing packages and, in Colab, fetches the course helpers.
Datasets and model weights are downloaded on first use into the git-ignored `data/` folder.
