# Revision and Sample Assessments

This folder contains **public revision materials** for students. They are representative samples written for study, not the actual examination papers.

| File | Purpose |
|---|---|
| `sample_quiz.md` | Short quiz for continuous revision (10 marks) |
| `sample_midterm.md` | Mid-term style paper for Weeks 1-7 (30 marks) |
| `sample_final.md` | Final-exam style paper for the whole course (40 marks) |

> **Note:** Current examination papers and grade records are kept private and are not part of this public repository, in line with IIUM academic policy.

## How to use these samples
1. Attempt the questions **closed-book** first.
2. Reveal the answers in the collapsible sections only afterwards.
3. For calculation questions, re-derive with your own numbers.
4. Cross-check the linked notebook for the practical version of each topic.

## Assessment weighting (accredited outline)
| Component | Weight |
|---|---|
| Quiz | 10% |
| Assignments | 20% |
| Mid-term | 30% |
| Final | 40% |
