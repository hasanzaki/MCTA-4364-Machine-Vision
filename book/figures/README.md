# Figures

Most figures in this book are **generated in code** inside the chapter `.qmd` files, so they stay reproducible and licence-clean.

Use this folder only for figures that cannot be generated in code (e.g. photographs from openly licensed sources). When you add one:

1. Record it in the figure register (see `../PROPOSAL.md`, Section 7).
2. Confirm the licence permits reuse (prefer CC0/CC BY).
3. Add attribution in the figure caption.
