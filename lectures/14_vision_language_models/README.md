# Week 14 - Vision-Language Models and Deployment
> **Official syllabus block:** Dynamic vision synthesis and modern machine vision frontiers.

## Learning objectives
- Explain how VLMs connect images and text.
- Perform zero-shot classification with CLIP.
- Caption images and answer visual questions.
- Discuss limitations and deployment.

## Key concepts
- Shared embedding space.
- Contrastive pretraining.
- Prompting.
- Hallucination, bias and privacy.

## Key formulas
- CLIP compares image and text embeddings by cosine similarity.
- Softmax over text prompts gives class probabilities.

## Common misconceptions
- A VLM is not a reliable detector or quantifier.
- Fluent, confident answers can be wrong.
- Large models may be unsuitable for hard real-time safety systems.
