# Practical Labs (Google Colab Notebooks)

Each folder below matches a week of the course. Every notebook follows the **same structure** so you always know what to expect:

1. **Learning objectives** - what you will be able to do after the lab.
2. **Setup** - a single cell to clone this repository and install packages.
3. **Guided examples** - short, runnable demonstrations with visualizations.
4. **Exercise** - a partially completed task for you to finish.
5. **Challenge** - an independent task that extends the concept.
6. **Reflection** - short questions to consolidate your understanding.

> Run every notebook from top to bottom. If you change the order of cells, rerun the whole notebook.
