# Data, image and model attribution

The course notebooks download all datasets and model weights at run time from their official sources.
Nothing below is redistributed in this repository. Always check the licence before using a dataset or model commercially.

| Asset | Used in | Source | Licence / terms |
|---|---|---|---|
| Fashion-MNIST | W06A | [zalandoresearch/fashion-mnist](https://github.com/zalandoresearch/fashion-mnist) (Xiao et al., 2017) | MIT |
| Imagenette (160 px) | W06B | [fastai/imagenette](https://github.com/fastai/imagenette) | Apache-2.0; images are a subset of ImageNet (non-commercial research and education) |
| `skimage.data` sample images (camera, chelsea, coffee, astronaut, rocket, coins) | many weeks | [scikit-image data](https://scikit-image.org/docs/stable/api/skimage.data.html) | public domain / CC0 (astronaut: NASA) |
| ResNet-18 ImageNet weights | W06B | [torchvision](https://docs.pytorch.org/vision/stable/models.html) | BSD-3-Clause (weights trained on ImageNet) |
| DeepLabV3-MobileNetV3 weights | W06B | [torchvision](https://docs.pytorch.org/vision/stable/models.html) | BSD-3-Clause (weights trained on COCO/VOC) |
| YouTube videos (3Blue1Brown) | W06A | embedded links only | © the creators; embedded, not copied |
