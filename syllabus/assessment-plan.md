# Assessment Plan

Aligned with the accredited course outline (MCTE 4323).

| Component | Weight | CLOs | Notes |
|---|---|---|---|
| Quiz | 10% | 1, 2, 3, 4 | Short written/online quizzes |
| Assignments | 20% | 1, 2, 3, 4, 5 | Lab notebooks and mini-project |
| Mid-term Examination | 30% | 1, 2, 3 | Weeks 1-7 material |
| Final Examination | 40% | 1, 2, 3, 4 | Whole course |
| **Total** | **100%** | | |

> The official outline also lists "Assignments" as CLO 5 in the mapping; here assignments are used to develop all four learning outcomes through the mini-project.

## Suggested continuous assessment design
- **Lab checkpoints**: each notebook has an Exercise and a Challenge. Mark the Challenge for a small grade.
- **Mini-project**: a complete pipeline (problem, data, model, evaluation, failure analysis, demo). See `projects/`.
- **Quiz**: conceptual, short-answer, based on the "Check your understanding" sections.

## Academic integrity
Labs may be discussed in groups, but submitted work must be individual unless stated otherwise. Cite any external code or dataset.
