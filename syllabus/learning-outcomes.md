# Course Learning Outcomes (CLOs)

**MCTE 4323 / MCTA 4364 Machine Vision** - Department of Mechatronics Engineering, IIUM.

Upon successful completion of this course, students will be able to:

| CLO | Statement | Domain | Assessed by |
|---|---|---|---|
| CLO1 | **Develop** machine vision systems using specific software tools. | Technical / Modern tool usage | Quiz, Assignments, Midterm, Final |
| CLO2 | **Apply** modern machine vision algorithms for engineering applications. | Technical / Problem analysis | Quiz, Assignments, Midterm |
| CLO3 | **Apply** 2D and 3D machine vision techniques for various engineering applications. | Technical / Design | Assignments, Midterm, Final |
| CLO4 | **Select** appropriate techniques for object recognition for various applications. | Analytical / Investigation | Assignments, Final |

## How the labs map to the CLOs

| CLO | Where it is developed |
|---|---|
| CLO1 | Every Colab notebook (Python, OpenCV, PyTorch, Ultralytics) |
| CLO2 | Weeks 5-7 (preprocessing and segmentation), Weeks 9-11 (detection and segmentation) |
| CLO3 | Week 3 (calibration), Week 12 (3D vision), Week 13 (motion) |
| CLO4 | Weeks 8-11 (features, detection, segmentation comparison) and the mini-project |
